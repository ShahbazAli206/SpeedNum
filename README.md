## Cloning

Screen recordings (`*.mp4`) are stored with [Git LFS](https://git-lfs.com), so you need it installed to get the actual video rather than a pointer file:

```bash
git lfs install
git clone https://github.com/ShahbazAli206/SpeedNum.git
```

If you already cloned without LFS, run `git lfs pull` in the repo.
